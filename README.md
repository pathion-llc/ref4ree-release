# Ref4ree releases

Released copies of Ref4ree, built for the GitHub check. Ref4ree is a commit gate: it checks an AI coding agent's work
instead of taking its word for it.

Each release holds one built program for Linux and its fingerprint. A project's GitHub check downloads a release and
runs it only when the fingerprint matches. The program judges nothing without a licence.
